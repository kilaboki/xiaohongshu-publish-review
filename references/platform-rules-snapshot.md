## 1. 《社区公约 2.0》（2026-01-19 上线）

替代旧版《社区公约》与《社区商业公约》，分三大板块共 25 条倡导。

### 1.1 真诚分享
- 尊重原创，分享真实内容
- 使用 AI 辅助创作时主动标明
- 不塑造虚假人设（财富、学历、收入、情感经历）
- 不过度裸露或含性暗示
- 不炫耀远超常人的消费能力
- 不用夸张、猎奇手段骗取点击
- 分享经过科学论证的内容
- 不冒充他人
- 未取得职业资质时，不提供医疗、投资、购房建议
- 保护未成年人身心健康，尊重个人隐私与人身财产安全

### 1.2 友好互动
- 友善沟通、换位思考
- 拒绝人肉搜索与任何形式的网络暴力
- 尊重不同性别、地域、种族、职业与兴趣
- 不恶意揣测分享动机
- 不轻易指控他人、不发布煽动性言论
- 保持社交距离，不骚扰、不发送不当内容
- 对有帮助的内容明确表达感谢
- 通过举报与「不喜欢」反馈不适内容

### 1.3 有序经营
- 提供真实商品与服务
- 不虚构功效、不伪造数据
- 亮明经营身份，提供真实有效信息
- 通过平台工具完成交易
- 不伪装素人、不干预用户评价、不滥发营销内容
- 不贬低竞争对手、不编造不实信息、不滥用举报
- 不以侵权手段达成经营目的

## 3. 图片与视觉相关要求

- 图中二维码、小程序码、外链、站外账号信息：系统会做图像扫描，命中即停止分发
- 联系方式（微信号、手机号）不得出现在任何图片区域，含角落小字与透明水印
- 其他平台水印、Logo、UI 截图：判搬运或导流
- 妆前妆后、减肥前后等过度修图对比：重点打击
- 后台数据截图不得涂改、拼接
- 封面文字占比建议 ≤ 30%，图片清晰度 ≥ 1080P
- 影视剧、综艺截图等无版权素材：侵权风险
- 图片内嵌字体需为可商用字体

## 4. 处罚梯度

警告 / 笔记限流 → 笔记下架、限制发布 → 限制私信、评论、直播 → 限制或关闭商品分享 → 扣分（信誉分 / 违规积分）→ 临时或永久封禁 → 依法追责。

补充事实：
- 历史笔记会被回溯巡检，旧笔记同样有风险
- 删除违规笔记不等于消除违规记录
- 批量删除大量笔记可能触发风控
- 矩阵账号、大小号联动导流会被连带处置

## 5. 2025-2026 重点治理方向

- 制造性别、地域、职业对立
- 虚假人设与虚假数据（封禁虚假账号、处置虚假营销笔记）
- 未报备的商业推广（野广）
- 无资质专业领域输出（医疗、医美、金融、教育）
- 站外导流与跨账号协同导流
