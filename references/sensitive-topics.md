# 敏感题材提醒

「敏感」指不必然违规、但会触发人工审核延迟、限流、举报风险或舆论反噬的题材。审核时**单独出一节提醒**，不并入阻断项，让用户自己权衡发不发、怎么发。

判定口径：**违规**看 `banned-words.md` 与官方规则；**敏感**看这份清单。同一内容可能两边都命中，取更严的一档并说明。

## 1. 高风险敏感（建议改角度或暂缓）　[P-01] [S-06]

| 题材 | 典型表现 | 后果 | 处理建议 |
|---|---|---|---|
| 时政与公共事件 | 政策评论、官员话题、国际冲突、涉港台疆藏 | 一律从严，账号风险最高 | 不碰，或只做纯生活化表达 |
| 灾难事故 | 蹭热点、现场拍摄、伤亡细节、阴谋猜测 | 下架 + 扣分，易被举报 | 等官方通报后做科普或互助信息 |
| 维权与曝光 | 点名商家/个人、晒聊天记录、律师函、举报流程 | 侵权投诉、名誉权纠纷、限流 | 隐去可识别信息，改为「我遇到的情况」 |
| 性别与地域对立 | 「所有男的/女的都…」、地域黑、职业歧视 | 重点治理项，明确处置 | 改成个人经历叙述，去掉群体概括 |
| 民族与宗教 | 宗教仪式、民族习俗评价、教义讨论 | 严格审核 | 不涉及评价性表述 |
| 军警与公职人员 | 制服、执法现场、内部信息 | 高风险 | 不拍不发 |
| 法律与司法 | 案件评论、判决质疑、未生效案件 | 侵权与干预司法风险 | 引用官方通报，不做定性 |

## 2. 中风险敏感（提醒但不拦）　[P-08] [S-04]

| 题材 | 典型表现 | 风险点 | 处理建议 |
|---|---|---|---|
| 健康与用药 | 偏方、替代药物、停药建议、剂量 | 无资质医疗建议；误导 | 加「个人经验，遵医嘱」，去掉疗效承诺 |
| 极端减肥 | 断食、催吐、代餐替代正餐、体重数字对比 | 健康导向风险，易被举报 | 改为科学饮食记录，去掉极端方法 |
| 医美 | 项目体验、术后对比、价格 | 资质与效果承诺 | 标注机构资质，避免绝对效果 |
| 心理与情绪 | 抑郁、自伤、轻生念头 | 危机干预责任 | 附求助渠道，避免细节描述 |
| 玄学与命理 | 算命、风水、塔罗、转运、招财 | 封建迷信，平台明确禁止宣扬 | 改为娱乐向表述并标注「仅供娱乐」 |
| 财富与收入 | 副业收入、搞钱方法、理财收益、炫富 | 虚假人设、炫富、金融违规 | 不晒具体金额截图，不承诺收益 |
| 两性情感 | PUA、婚恋焦虑、出轨、彩礼 | 对立与焦虑营销 | 去标签化，讲个人故事 |
| 教育升学 | 保过、升学率、内卷对比、鸡娃 | 教育焦虑、绝对化承诺 | 讲方法不讲结果 |
| 法律灰色 | 代购、转卖、拼单、代办 | 平台禁止营销倾向内容 | 不引导交易 |
| 食品与添加剂 | 「毒食品」、致癌物、添加剂恐慌 | 谣言风险，易被判不实 | 引用权威来源，不做恐慌式表述 |
| 猎奇与血腥 | 伤口、手术过程、尸体、事故现场 | 首图血腥直接违规 | 换图或不发 |
| 动物与野生 | 野生动物交易、虐待、救助争议 | 违法与舆情双重风险 | 只发合规救助信息 |
| 赌博彩票 | 彩票技巧、博彩、抽奖引流 | 违法信息 | 不发 |

## 3. 提示写法

每个敏感项按这个格式写，不要只丢一个词：

```
【敏感提醒】性别对立：第 2 段「男生根本不懂…」属于群体概括，属于平台重点治理方向，容易引发评论区对立并被举报。建议改为个人经历：「我遇到的情况是…」。
```

## 4. 与违规的边界

- 命中法律法规或官方明令禁止的（政治、色情、赌博、毒品、暴力教唆）→ 直接进「阻断项」，不叫敏感。
- 只是容易引发争议、审核慢、限流的 → 进「敏感提醒」。
- 拿不准时按敏感处理，并在提醒里说明「可能被判定违规，建议谨慎」。
