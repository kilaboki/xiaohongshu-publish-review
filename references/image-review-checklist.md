# 图片审核清单

图片审核和文案一样，每条结论要有**部位、现象、依据、改法**四件套。依据编号见 `evidence-index.md`。

## 一、执行方式

1. **逐张实际查看**：用 Read 打开每张图片文件，不依赖文件名、用户描述或缩略图。用户在对话里贴的图同样逐张看。
2. **分区扫描**：每张图按「四角 → 文字区 → 主体 → 背景 → 边缘」五个区域看一遍。二维码与联系方式通常藏在角落、贴纸、屏幕截图和设备 UI 里。
3. **放大细节**：文字小、水印淡、logo 被遮挡时，裁切放大再看；看不清就说明「该处无法确认」，不要默认通过。
4. **按顺序判定**：A 阻断 → B 高风险 → C 建议，命中即记录，不因后面还有问题而跳过前面的。

## 二、阻断项

| # | 检查项 | 依据 | 发现方法 | 改法 |
|---|---|---|---|---|
| A1 | 二维码 / 小程序码 / 条形码 | P-06 | 四角、贴纸、名片、书页、商品包装、手机屏幕、海报、名片、付款码；破损或模糊的码同算 | 裁切、模糊处理或重拍；需要引导时改成站内动作文字 |
| A2 | 个人联系方式 | P-06 | 微信号、手机号、QQ、邮箱、详细地址；角落小字、半透明水印、手写体 | 完全移除；改用「评论区交流」「主页合集」 |
| A3 | 其他平台联系方式与链接 | P-06 | 网址、淘宝口令、店铺链接、公众号名 | 移除或替换为站内路径 |
| A4 | 其他平台水印与界面 | P-06 / P-12 | 抖音、快手、B 站、视频号水印；带对方平台 Logo 的 UI 截图 | 换无水印原图；无法获取则裁切或重制 |
| A5 | 其他账号标识 | P-06 | 他人小红书号、微博昵称、店铺名水印 | 去掉或换成自己的账号 |
| A6 | 无资质专业内容 | P-05 / L-05 / L-02 | 处方药、医疗器械、诊疗方案、注射类项目、荐股与保本理财 | 删图或改为不含具体方案的经验分享 |
| A7 | 首图血腥恐怖 | P-07 | 伤口、手术过程、事故现场、尸体、血污 | 换图，不作为首图 |

## 三、高风险项

| # | 检查项 | 依据 | 发现方法 | 改法 |
|---|---|---|---|---|
| B1 | 过度修图与效果对比 | P-07 / P-08 / L-04 | 妆前妆后、减肥前后、美白对比、身材对比；背景扭曲、比例失真、皮肤零纹理 | 保留对比时注明光线、时间、是否滤镜；去掉「N 天见效」类标注 |
| B2 | 数据截图 | P-10 / L-04 | 后台数据、收益、销量、粉丝数；看时间是否一致、边缘有无拼接、数字是否被涂改 | 不晒具体金额；需要证明时只给区间并说明统计口径 |
| B3 | 竞品对比与贬损 | L-08 / S-05 | 竞品 Logo 被遮挡、打叉、贬损标注；对比图中故意丑化对方 | 去掉对方品牌标识；改为讲自己的使用感受 |
| B4 | 裸露与性暗示 | P-04 | 过度暴露、低俗姿势、暗示性构图、局部特写 | 换图或裁剪；文案同步调整 |
| B5 | 未成年人 | P-02 / L-09 | 儿童正脸、校服与学校名、家庭住址、带商品的儿童代言感画面 | 打码或去掉正脸；避免商业化呈现 |
| B6 | 版权素材 | P-12 / L-10 | 影视剧截图、综艺画面、明星肖像、他人摄影作品、知名 IP 形象、商用字体外的字库 | 换原创或已授权素材；字体换成可商用 |
| B7 | 图内文字违规 | 见 `banned-words.md` | 图上的极限词、功效断言、导流话术、虚假承诺 | 按词表替换；图内文字量大时重做版式 |
| B8 | 危险行为示范 | P-09 | 无防护的高空、明火、危险驾驶、危险挑战 | 加安全提示或换图 |

## 四、建议优化

| # | 检查项 | 依据 | 改法 |
|---|---|---|---|
| C1 | 首图文字占比过高 | N-01 | 精简到 3-5 个短句，或把信息挪到正文 |
| C2 | 清晰度不足 | N-02 | 换原图；避免二次压缩与拉伸变形 |
| C3 | 比例不合适 | N-04 | 竖图改 3:4 或 1:1，主体不要被裁切 |
| C4 | 构图与主体 | 经验 | 主体居中或按三分法；去掉无关杂物 |
| C5 | 多图风格不一致 | 经验 | 统一色调、字体、版式与信息层级 |
| C6 | 凑数图 | 经验 | 删除信息重复的图，宁少勿滥 |
| C7 | 图文不符 | P-07 | 封面与正文主题一致，不夸大 |

## 五、视频笔记

- 抽帧检查：片头 3 秒、片中每 10 秒、片尾 3 秒
- 背景中的二维码、水印、招牌、屏幕内容同样按 A 类检查
- 字幕按 `banned-words.md` 扫一遍
- 片尾联系方式与引导关注话术重点看

## 六、长图与拼图

- 放大检查拼接处，常藏联系方式与水印
- 多张截图拼合时检查是否拼接伪造（B2）
- 长图底部容易被裁切，确认关键信息完整

## 七、输出格式

每张图给一段，四件套齐全：

```
图 2｜部位：右下角 + 底部边缘
现象：半透明「抖音」水印；左下角小字「+V: abc123」
依据：[P-06] 禁止导流到其他平台的网址链接、二维码、水印
判定：阻断
改法：换无水印原图；联系方式完全移除，改为「主页合集里有整理」
```

通过时也要写检查范围，证明不是漏看：

```
图 1（封面）｜已查：四角、文字区、主体、背景、边缘
结论：通过
```

无法确认时明确标注：

```
图 3｜部位：背景招牌
现象：文字模糊，无法辨认是否为联系方式
结论：无法确认，建议换图或提供原图
```
