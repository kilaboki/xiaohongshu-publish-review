# 小红书发布前审核 · Xiaohongshu Publish Review

一个给 AI Agent 用的发布前审核 skill。审文案、审图片、标敏感题材，每条结论都带**规则依据**和**具体改法**。

不是又一个违禁词替换器——它解决的是「凭什么说这条违规」和「我该怎么改」。

## 能做什么

| 能力 | 内容 |
|---|---|
| 文案审核 | 站外导流、绝对化用语、功效宣称、虚假夸大、诱导互动、商业合规、特殊品类、未成年人、AI 与原创 |
| 图片审核 | 二维码与联系方式、他平台水印与 UI、竞品与品牌标识、过度修图与效果对比、裸露与性暗示、未成年人、版权素材、图内文字、封面排版 |
| 敏感提醒 | 18 类题材分两档：高风险敏感（时政、灾难、维权曝光、性别地域对立等）与中风险敏感（玄学、极端减肥、医美、财富收入等） |
| 图文交叉 | 文案承诺与图片证据是否一致、封面与正文是否相符、多图之间是否矛盾 |
| 证据引用 | 每条问题落到具体条款编号，附原文要点 |
| 改进意见 | 文案给可直接复制的改写版；图片给具体改法（裁哪块、换什么图、怎么重拍） |

## 为什么说「有依据」

审核结论不是凭感觉写的。所有判定走一套编号体系（`references/evidence-index.md`）：

- `P-xx` 小红书《社区规范》官方原文
- `S-xx` 专项规则与《社区公约 2.0》
- `L-xx` 《广告法》《化妆品监督管理条例》《民法典》《反不正当竞争法》等
- `N-xx` 平台技术要求与行业口径

示例输出：

```
第 2 段「全网最低价，一片顶三天」
依据：[L-01] 《广告法》第九条禁止「国家级」「最高级」「最佳」等用语
      [L-02] 非医疗广告不得涉及疾病治疗功能
判定：阻断
改法：改为「我用下来性价比不错，一片大概能用三天」
```

找不到条款支撑的判断会被降级，不会硬判「阻断」。

依据分四类来源，可靠性不同：

| 类型 | 编号 | 来源 | 可靠性 |
|---|---|---|---|
| 官方原文（已抓取） | `P-xx` | 官方数据接口拉取，含内容哈希 | 高，可复现 |
| 法律条文 | `L-xx` | 条目为国标要点，附官方数据库检索入口 | 条文稳定，入口已验证 |
| 公开公告归纳 | `S-xx` | 官方公告与权威转载整理 | 中，随公告更新 |
| 行业口径 | `N-xx` | 平台公开要求与经验 | 参考值 |

## 规则怎么保持最新

平台规则会变，所以 skill 每次运行先核对官方原文：

```bash
python -I scripts/fetch_official_rules.py
```

脚本直接读取小红书官方公开数据接口，取回《社区规范》全文，用内容哈希判断是否变化：

- `UNCHANGED` — 官方内容未变，直接引用本地原文
- `CHANGED` — 打印新旧哈希，提示读差异并更新
- `FETCH_FAILED` — 接口异常，明确报错，转用检索并标注「官方原文未核验」

`--update` 会重写 `references/official-community-rules.md`。

《社区公约 2.0》与专项治理公告没有公开接口，按 `references/rule-sources.md` 的检索词补充。

## 安装

```bash
git clone https://github.com/kilaboki/xiaohongshu-publish-review.git \
  ~/.agents/skills/xiaohongshu-publish-review
```

适用于 Claude Code / ZCode 等支持 `~/.agents/skills/` 目录的 Agent。其他 Agent 也可以直接把 `SKILL.md` 当作系统提示词使用。

依赖：Python 3.8+（脚本只用标准库）。

## 使用

对 Agent 说：

- 「审一下这篇小红书」
- 「这篇会不会被限流」
- 「帮我检查配图有没有问题」

然后给出文案正文与图片路径（或直接贴图）。Agent 会按 `SKILL.md` 的流程输出：

```
## 审核结论
判定 / 规则基线 / 未覆盖范围

## 阻断项
## 高风险项
## 建议优化
## 敏感题材提醒
## 图片逐张结论
## 改写后完整文案
```

## 目录结构

```
.
├── SKILL.md                          # 主流程与输出规范
├── references/
│   ├── evidence-index.md             # 依据编号表（P/S/L/N）
│   ├── official-community-rules.md   # 官方《社区规范》原文（脚本生成）
│   ├── platform-rules-snapshot.md    # 公约 2.0、专项规则、处罚梯度
│   ├── rule-sources.md               # 官方入口、刷新流程、失效判定
│   ├── banned-words.md               # 违禁词分类与替换建议
│   ├── sensitive-topics.md           # 敏感题材清单与提醒写法
│   └── image-review-checklist.md     # 图片逐项检查与改法
└── scripts/
    └── fetch_official_rules.py       # 官方规则抓取与更新检测
```

## 局限

- 图片审核依赖 Agent 的视觉能力，模糊、遮挡、极小的文字可能看不清；看不清时会标「无法确认」，不会默认通过。
- 视频笔记只能抽帧检查，口播语音不在覆盖范围。
- 《社区公约 2.0》无公开接口，靠检索补充，可能滞后。
- 平台审核还有账号权重、实时策略等内部因素，本 skill 无法覆盖。
- 审核结论仅作发布前参考，不构成法律意见，也不保证一定通过平台审核。
